## サマリ

非表示・格納の見え方を「お道具箱にしまう」「お道具箱から取り出す」という操作感へ寄せた。既存の stage/unstage ロジックは維持し、ユーザーに見えるラベル、アイコン、ヘルプ、README の表現をそろえた。

## 画面: 上部ホバーバー

### 何が変わったか（WHAT）

- 格納済みセクションの見出しを「格納中」から「お道具箱」に変更。
- 表示/非表示トグルの eye アイコンを、しまう操作は `archivebox.fill`、取り出す操作は `tray.and.arrow.up.fill` に変更。
- 格納済みウィンドウの位置バッジを「格納」から短い「箱」に変更。
- コンテキストメニューを「お道具箱にしまう」「お道具箱から取り出す」に変更。
- 通常カードのドラッグ中に「下へドラッグしてお道具箱へ」というドロップ先を表示し、列の下端を越えて離すとお道具箱へしまえるように変更。
- お道具箱内カードのドラッグ中に「上へドラッグして作業台へ」というドロップ先を表示し、上へ引き出して離すと作業台へ戻せるように変更。
- 閉じた状態の上部バーを細線から「お道具箱」の取っ手へ変更し、しまった数がある場合は `お道具箱 N` と表示するように変更。
- パネル高さ計算に取っ手とドラッグ用ドロップ先の予約領域を加え、上部ホバーの上下が見切れないように変更。

### なぜ変えたか（WHY / UX上の意図）

- 「非表示」は消える印象が強いが、「お道具箱」は一時的に作業台から外すだけだと伝わる。
- 取り出し先が上部バーにあるため、隠した後の所在が分かりやすくなる。
- ボタンを狙わなくても、カードを作業台の外へ放り込むようにしまえるため、比喩と操作が一致する。
- しまったカードを上へ引き出せることで、「箱から取り出す」操作も同じ直接操作として成立する。
- ドラッグ開始後に追加されるドロップ先でパネル外枠が足りなくならないよう、必要な高さをあらかじめ確保する。

## 画面: メニューバー

### 何が変わったか（WHAT）

- 格納済み一覧の見出しを「お道具箱」に変更。
- 各行の操作文言を「復帰」から「取り出す」に変更。
- アクションを「フォーカスウィンドウをしまう」「お道具箱から全て取り出す」に変更。

### なぜ変えたか（WHY / UX上の意図）

- メニューから操作しても、ホバーバーと同じ比喩で理解できるようにするため。
- 「全復帰」より「全て取り出す」のほうが、箱から戻す操作として自然に読めるため。

### 確認した観点

- [x] `swift build` が成功すること
- [ ] 実機メニューで文言が長すぎないこと
